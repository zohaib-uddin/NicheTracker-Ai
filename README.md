# Niche Tracker AI – Viral Content Trend Analyzer

Niche Tracker AI is a web application designed for content creators who want to discover **daily trending niches for TikTok and YouTube Shorts**.
The platform automatically tracks trending topics and viral niches using AI and external APIs, helping creators find high-potential content ideas every day.

The goal of this project is to help creators stay ahead of trends and create viral short-form content more consistently.

## ⚡ How It Works

1. The system collects trending data from the **TikTok API**.
2. Data is processed and analyzed using **Google Gemini AI**.
3. AI identifies potential **viral niches and content opportunities**.
4. The platform updates the trending niche list **daily**.
5. Content creators can explore niches and plan their next viral video.

## 📦 Installation

To run the project locally:

1. Clone the repository

```bash
git https://github.com/zohaib-uddin/NicheTracker-Ai.git
```

2. Navigate to the project folder

```bash
cd nichetrackerai
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```
